* **GitHub Pages** – Hosting statického webu
* **`.nojekyll`** – Konfigurace sestavení na GitHub Pages

* **Backend:** Python, Flask framework
* **Databáze:** SQL, MariaDB / MySQL, Adminer
* **Nástroje:** Git, GitHub, VS Code, XAMPP
